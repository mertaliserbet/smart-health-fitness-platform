# Trainer dashboard antrenman özeti

Trainer, dashboard'da aktif danışanlarından birini seçerek antrenman özetini açar. Danışan seçilmeden program veya oturum isteği gönderilmez; bütün danışanlar için ayrı ayrı istek yapılmaz. Kullanılan mevcut endpointler API_CONTRACT 15.2 ve 16.4'tür: GET `/api/users/{userId}/workout-plans` ve GET `/api/users/{userId}/workout-sessions?page=1&pageSize=20`. Yeni endpoint, DTO, şema veya migration eklenmez. Bu çalışma diyetisyen beslenme ilerlemesi PR'ına bağımlı değildir.

Program atamaları aktif ve geçmiş listenin toplamıdır. Toplam oturum sayısı ilk sayfadaki satır sayısından değil API `totalCount` alanından alınır; son beş oturum API sırası korunarak gösterilir. Tüm durumlar dahildir. `Completed`, oturumun sona erdiğini ifade eder; tüm egzersizlerin tamamlandığı varsayılmaz. Kart gerçek `completedExerciseCount / totalExerciseCount` değerini gösterir. Veri yoksa sıfır/boş durumları gösterilir; API hatasında sayılar uydurulmaz ve yeniden deneme vardır.

Tek `IsActive` program, tarihi henüz başlamamış veya bitmiş olsa da aktif atama olarak gösterilir; durum etiketi ayrıca başlangıç/bitiş sınırlarını kapsayıcı karşılaştırır. Tarih durumu, mevcut oturum başlatma API'sinin UTC takvim günü kuralını kullanır. Program düzenleme veya oturum yazma yapılmaz; mevcut program, geçmiş, oturum detayı ve profil ekranlarına geçiş bağlantıları vardır. `Özeti yenile` sunucudan tekrar okur.

Admin/Dietitian panelinde bu bölüm ve istekler yoktur. Demo panelinde gerçek Trainer girişi açıklanır; gerçekmiş gibi oturum sayısı gösterilmez. Danışan değişimi eski yüklemeyi iptal eder; önceki danışanın yanıtı yeni özette gösterilmez. Okuma yetkileri mevcut backend'in aktif Trainer ilişkisi/güncel hesap/rol kontrolleriyle uygulanır. Yanıt alanları, tarih/enum/sayı/pagination tutarlılığı ve oturum kullanıcı kimliği web'de doğrulanır; bozuk yanıt örnek veriyle değiştirilmez.

Web testleri seçim öncesi istek yokluğunu, toplam ile son beş kayıt ayrımını, boş program/geçmişi, API hatası/yeniden deneme/yenilemeyi, demo ve rol sınırlarını, geç gelen eski yanıtın iptalini ve program tarih sınırlarını kapsar. Gerçek tarayıcı/API/PostgreSQL kontrolünde ilk sayfadan fazla 25 oturumla toplam, son beş kayıt, kısmi tamamlanan oturum detayına geçiş ve boş danışan doğrulanmıştır. Stil kendi dosyasında tutulur; 390 ve 1280 piksel düzenleri kontrol edilir.
